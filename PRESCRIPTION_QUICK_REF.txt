║  🔹 SWIFTPHARMA PRESCRIPTION INTELLIGENCE ENGINE - QUICK REF     ║
╚═══════════════════════════════════════════════════════════════════╝

📍 API ENDPOINT
───────────────────────────────────────────────────────────────────
POST http://localhost:5000/api/ai/scan-prescription

Request Body:
{
  "ocrText": "Your prescription OCR text here..."
}


🎯 CORE BEHAVIOR
───────────────────────────────────────────────────────────────────
✓ Detects ALL medicines (never stops at first)
✓ Each medicine = separate object
✓ Returns null for unclear fields (never invents data)
✓ JSON-only output


🔢 QUANTITY FORMULA
───────────────────────────────────────────────────────────────────
total_quantity = frequency_per_day × duration_days

If either is null → total_quantity = null


🧠 DOSAGE RULES
───────────────────────────────────────────────────────────────────
1-0-1 → 2    |  OD  → 1
1-1-1 → 3    |  BD  → 2
2-1-2 → 5    |  TDS → 3
             |  QID → 4


📤 OUTPUT STRUCTURE
───────────────────────────────────────────────────────────────────
{
  "medicines": [
    {
      "name": "Paracetamol",
      "strength": "650 mg",
      "dosage_pattern": "1-0-1",
      "frequency_per_day": 2,
      "duration_days": 5,
      "total_quantity": 10,
      "confidence": 0.93
    }
  ],
  "doctor": { "name": "...", "qualification": "..." },
  "hospital": "...",
  "prescription_date": "2026-01-24",
  "safety_flags": {
    "duplicate_medicines": false,
    "unclear_dosage": false,
    "missing_duration": false,
    "handwritten_uncertain": true
  }
}


🔍 EXTRACTION STRATEGIES
───────────────────────────────────────────────────────────────────
1. Line-by-line scan (PRIMARY)    → High confidence
2. Structured fields   (SECONDARY) → Medium confidence
3. Pattern-based       (FALLBACK)  → Low confidence


⚠️ FALLBACK BEHAVIOR
───────────────────────────────────────────────────────────────────
If data is messy:
  • Return multiple medicine objects
  • Use null where unsure
  • Never return empty array if medicines exist


🚨 NEVER DO
───────────────────────────────────────────────────────────────────
❌ Stop at first medicine
❌ Merge multiple medicines
❌ Invent dosage/duration
❌ Return text or explanations
❌ Return empty medicines array if patterns exist


✅ ALWAYS DO
───────────────────────────────────────────────────────────────────
✓ Extract ALL medicines
✓ Use null for unclear fields
✓ Return JSON only
✓ Calculate total_quantity if possible
✓ Score confidence (0.0 - 1.0)
